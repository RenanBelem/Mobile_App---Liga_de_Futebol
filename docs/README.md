## 💰 Investimento Necessário

### Desenvolvimento (0 horas até lançamento)
- **Custo:** $0 (você faz)
- **Tempo:** ~50-60 horas (2-3 meses)

### Infraestrutura (Primeiros 12 Meses)
- **Frontend Hosting:** Gratuito (Vercel)
- **Backend Hosting:** Gratuito (Supabase free tier / Railway créditos)
- **Banco de Dados:** Gratuito (até 5GB)
- **Total:** $0

### Produção (Após lançamento)
- **Frontend:** ~$0-20/mês (Vercel Pro opcional)
- **Backend:** ~$25-45/mês (Supabase Pro ou similar)
- **Total:** ~$25-65/mês
