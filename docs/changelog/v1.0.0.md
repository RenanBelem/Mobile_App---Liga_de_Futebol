## 🎉 O Que É Esta Versão?

**MVP (Minimum Viable Product)** - A primeira versão funcional da Liga Antifascista de Futebol com todos os recursos essenciais para gerenciar times, jogadores e visualizar torneios.

## ⚠️ Limitações Conhecidas (Será Feito em v1.1 ou v2.0)

### Backend e Banco de Dados
- ❌ **Sem backend real** - Dados não sincronizam entre dispositivos
- ❌ **Sem banco de dados** - Tudo em localStorage (máx 5-10MB)
- ❌ **Sem autenticação JWT** - Senhas não verificadas no servidor
- ❌ **Sem API REST** - Sem integração com servidor

### Recursos Avançados
- ❌ **Sem PWA** - Não funciona offline ainda
- ❌ **Sem upload de arquivos** - Logos/fotos ficam em localStorage
- ❌ **Sem live updates** - Sem sincronização em tempo real
- ❌ **Sem mobile app nativa** - Sem iOS/Android ainda

### Funcionalidades Planejadas
- ❌ **Cadastro de Torneios** - Desabilitado ("Em breve")
- ❌ **Configurações** - Desabilitado ("Em breve")
- ❌ **Sistema de pontuação** - Não implementado
- ❌ **Chat/Mensagens** - Não implementado

## 🚀 Como Usar Esta Versão

### Primeira Execução
```bash
npm install
npm run dev
```

### Testar Funcionalidades
1. **Cadastro:** Vá em "Mais" → Cadastrar usuários/times/jogadores
2. **Visualização:** Veja dados em "Times", "Torneios", "Média"
3. **Debug:** Acesse `http://localhost:8080/debug` para ver dados
